## 首个可运行迭代的工程选择

- React + TypeScript + Vite / FastAPI + Pydantic + SQLAlchemy。
- 本地 SQLite WAL + 私有本地资产目录，降低无凭据环境的启动门槛；可配置 PostgreSQL 连接，但当前验证仅覆盖 SQLite。
- 当前用持久数据库队列、事务领取、心跳与独立 Worker；无需 Redis。运行进程重启后 queued 任务可继续，过期 running 任务标为结果未知，付费任务不盲目重放。Celery/Redis 与对象存储留到部署迭代，不声称已经接入。
- 当前使用带租户归属的版本化 records 表，保留 JSON 业务快照；后续按查询负载拆分关系表，并补充数据库级约束。
- 默认每种模式 3 款、每次咨询最多 18 次图像尝试。预留整批金额，未知费用不释放或视为免费；当前没有账单自动核对。
- 真实适配器采用仅允许指定官方 HTTPS 端点的请求；图像要求 b64_json 响应，避免抓取任意返回 URL。该响应能力必须通过开通账号后的冒烟测试验证。
