# 不保存图片的轻量试用版

用户已明确确认：选照片 → 网页调用模型 → 展示 → 发型师审核 → 用户下载保存。首版不接 R2 / OSS / COS / GitHub 图片仓库；不提供跨设备图库和关闭后的后台恢复。

## 数据处理

- 浏览器校正照片方向、缩放至最长边 1536 并转成 JPEG，移除 EXIF；照片只在当前页面内存中。
- Worker 在请求处理中临时接收照片，转发给 Qwen / Seedream。服务器不写入图片文件、对象存储、数据库 BLOB、Base64 图片或临时图片 URL。
- Seedream 返回临时官方图片 URL。服务器仅记录其哈希并发给当前浏览器一个短期签名凭证；图片经受控接口流式传到浏览器 Blob。Qwen 直接读取厂商临时 URL 做评审，无需我方存储。
- 照片和效果图不进入 LocalStorage、SessionStorage、IndexedDB 或 Service Worker 缓存。刷新、关闭或结束咨询会丢失未下载图片；页面有文字提示与离开提醒。
- D1 仅存账号、加密模型配置、本轮确认条件、图片指纹、候选结构、用量/次数与审核元数据。请求体、原图和临时 URL 不写日志。
- 本轮元数据 24 小时后不可访问，过期数据在新建咨询时清理。模型厂商的处理和留存独立遵循其政策；不能承诺第三方零留存。

## 功能与约束

- 默认两类各 3 款，分别评分；不足显示阶段结果，不凑数。
- 一次咨询累计 18 次图像尝试；成功、失败和未知调用都占已提交尝试。无金额必填。
- 逐张查看后才能审核；服务端复核硬约束与当前版本。只允许当前版本已审核的 ≤9 张图片进入展示与下载。
- 进入顾客展示会话后销毁工作区会话。下载仅限已审核集合；结束后需要重新登录。
- 可下载单张图片或 ZIP。ZIP 在浏览器本地生成，无需上传到服务器；手机一般保存到文件或下载目录，不保证自动进入相册。
- 重试只有明确手动操作；不会因供应商失败自动返回演示成功。请求未知时提示可能计费，不自动重发。
- 演示模式绘制带明确水印的结构插画与模拟评分；不冒充真实顾客效果。

## 首次使用

1. 打开已部署的测试网站，使用被忽略目录 `.runtime/cloudflare-login.txt` 中的私有账号密码。
2. 进入“模型设置”，安全填写真实 Qwen 和 Ark API Key。模型型号固定为 Qwen3-VL-Plus 和 doubao-seedream-5-0-flash-260915。
3. 密钥通过 HTTPS 进入受保护接口，AES-GCM 加密存入 D1；主密钥保存在 Cloudflare Secret，不进入前端或 Git。之前云环境中的代理绑定值不会被复制到远端。
4. 先演示测试，再用获授权照片做真实测试。选择照片前必须确认授权，完成下载后再关闭。

## 部署

`scripts/deploy-cloudflare.py` 仅创建 Worker + D1，不创建存储桶、队列或付费订阅。SQL 迁移通过官方 D1 query API 完成，避免批量导入客户端的网络问题。生成的管理员登录信息只保存到 chmod 600 的私有本地文件，不输出到聊天或日志。
