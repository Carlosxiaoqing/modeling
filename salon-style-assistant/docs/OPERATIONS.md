# 运行与排障

## 更新与迁移

在项目根目录运行 `bash scripts/install.sh`，可重复执行。数据库迁移在 backend 目录执行 `uv run alembic upgrade head`；不会覆盖用户照片或账号。安装脚本会加载项目根目录的 .env；没有该文件时使用当前进程环境与默认本地数据库。外部数据库请先正确配置 DATABASE_URL。

## 备份与恢复（本地开发）

先停止自己启动的 API 和 Worker，完整复制 `.runtime/` 到工作区外的安全备份位置；SQLite 的数据库与 WAL、资产必须来自同一停机时点。恢复到新的私有 DATA_DIR，再启动 API，验证账号、咨询、图片和展示访问。没有实际执行备份恢复演练；真实部署还需数据库和存储的独立备份策略。

## 删除与保留

通过工作台删除按钮删除咨询。默认 30 天是建议保留期限，当前没有定时自动清理器；试点前必须加入并验证。删除会即时撤销本地访问并删除原图/效果图；未保存解码前原始上传，保留的是去 EXIF 的标准化参考图。供应商和备份的留存不在本地删除保证之内。

## 常见问题

- 无页面：先在 apps/web 构建，然后重启 API（静态路由在进程启动时注册）。
- 503 MODEL_NOT_CONFIGURED：检查变量名称及是否存在，不打印值；核实模型账号、区域和权限，不自动换型号。
- PHOTO_QUALITY_BLOCKED：补充正面和侧面，真实模式先完成分析；严重质量问题不能跳过。
- PROFILE_REVISION_CONFLICT：刷新并检查新版条件。旧版审核不能复用。
- 结果不足：补充可靠长度、调整真实限制，或者只发布阶段预览；不能硬凑方案。
- PROVIDER_RESULT_UNKNOWN：外部调用可能已收费，不重新无限提交。核对供应商请求和费用，当前预留仍占预算。
- 422 上传失败：只接受实际可解码 JPEG/PNG/WebP、≤15 MB、≤40 MP、短边≥160。HEIC 请转码。
- 浏览器下载 403：本云环境已存在 `/usr/bin/chromium`，测试使用它；无需关闭 TLS 校验或改变网络策略。
- uv 缓存只读：设置 `UV_CACHE_DIR=/tmp/salon-uv-cache`，不修改系统目录权限。
